First packaged release of the Ember Firefox fork, based on OldTweetDeck v4.4.0.

- Warm dark theme with IBM Plex Sans, compact article cards and colored column headers.
- Whole columns hide cleanly when the window narrows.
- Smooth incoming-tweet animations, with no tweet-row hover background change.
- Firefox image-startup fix, bounded duplicate caches and reduced observer overhead.
- Modular interceptor source and 40 regression tests.

Download OldTweetDeckFirefox-Ember.zip below. This is an unsigned Firefox extension package: for temporary installation, use about:debugging → This Firefox → Load Temporary Add-on and select the ZIP, then reload TweetDeck. Temporary installations end when Firefox restarts. Permanent unsigned installation requires a Firefox build/configuration that supports it; this is not a Mozilla-signed add-on.

Includes all prior local customizations. The existing upstream runtime-update behavior remains enabled unless you select the local-only option.
